# Surge SMP resource packs

The three resource packs the Surge SMP server sends on join. This repository is public for one
reason: a Minecraft client downloads a resource pack anonymously, with no token and no auth
header, so the URLs have to be reachable by a stranger. Nothing else lives here — the plugin is
private.

**They only work applied together**, and the order matters.

| # | Pack | Supplies |
| --- | --- | --- |
| 1 | `Shader2.zip` | `ult_effects` fonts (the parry overlay), `ritualvfx`, the `custom.clock` sound, particle shaders |
| 2 | `surgepack.zip` | HUD glyphs, the fullscreen title overlay, the custom sound set, text shaders, the four fragment shard items, the Lunar icon, star and moon, Living End's art (`assets/livingend/`), the Surge Cell, the Eclipse's six bones |
| 3 | `spherpack.zip` | The raysphere models, the `raysphere_marker` textures, and the core shader that raytraces them |

Lowest priority first. Minecraft merges `sounds.json` and font providers across the whole stack,
so those combine — but models, textures and shaders do not. For those the highest pack that ships
a file wins outright, which is why `spherpack.zip` has to sit on top: `surgepack` ships raysphere
models but not the textures they reference, so with surgepack winning the core renders untextured.

## Hashes

The server sends each pack with its sha1 so clients can reuse a cached copy. These are the hashes
of the zips in this repository at the latest tag. From Lunar onward, surgepack is served straight from the
commit that added it rather than from a release asset. A commit url never changes underneath the sha1,
the same guarantee a release gives. surgepack `v16` is at
`https://raw.githubusercontent.com/seeedey/surge-packs/d605b5a9c2188e72c7385ed5ed168e498b85da7f/surgepack.zip`
(and `v15`, for rollback, is still at `.../7bb84b28dc045762c53d91bdf85305de10e64a26/surgepack.zip`,
sha1 `f7f23d772793fca23546bd9fd067e524f0921998`):

```
Shader2.zip     55219f777e5a140546ee601b7bc9392a91816aaf
surgepack.zip   75d9c6bc9f0e1cadea4f5ed27e5413f4ccf3ab49
spherpack.zip   8aab0d79816008859f40b1502cffa1fbc1abb503
```

**Re-hash after every pack edit.** A stale hash means either a re-download on every join or a load
failure, and the server is configured to kick on a load failure.

```powershell
certutil -hashfile surgepack.zip SHA1
```

## surgepack v16: Spider and Disable

`v16` is `v15` with every entry byte-identical (same offsets, same compressed bytes, same
`pack.mcmeta`) and 9 entries appended under `assets/surge/`. 5,717,938 bytes. It adds:

- **Two element icons**, `textures/hud/spider.png` and `textures/hud/disable.png` (32x32, drawn by
  `tools/make-spider-disable-icons.py` in the plugin repository), bound as U+E01C and U+E01D in a
  **new font, `surge:icons`**. They are not in `minecraft:default` because a release appends and the
  default font file cannot be appended to; the plugin names the font on the charge bar.
- **Two element stars**, `surge:spider_star` and `surge:disable_star`: item definition, model and the
  same tile again under `textures/item/`.

Like v15, it touches nothing outside its own namespace.

## surgepack v15: the Surge Cell and the Eclipse

`v15` is `v14` with every entry byte-identical (same offsets, same compressed bytes, same
`pack.mcmeta`) and 16 entries appended under `assets/surge/`. 5,713,309 bytes. It adds:

- **The Surge Cell**: `surge:surge_cell`, its item definition, model and a 16×16 texture — a
  copper-capped glass cell standing upright with a lightning bolt in it. Generated by
  `tools/make-surge-cell.py` in the plugin repository.
- **The Eclipse**: the Eight Phases boss's skin (`textures/item/eclipse.png`) and its six bones
  (`eclipse_head`, `eclipse_body`, `eclipse_arm_left`, `eclipse_arm_right`, `eclipse_leg_left`,
  `eclipse_leg_right`), each an item definition and a model, cut onto Pandora's rig by the plugin's
  `tools/rig.py`. Nothing asks for them until the plugin's `phases.eclipse.rig` is turned on.

Like v14, it touches nothing outside its own namespace, and every texture it adds is under
`textures/item/`.

## surgepack v14: Living End

`v14` is `v13` with every entry byte-identical (same offsets, same compressed bytes, same
`pack.mcmeta`) and 119 entries appended under `assets/livingend/`: Living End's art, generated by
`LivingEnd/tools/art.py` in seeedey/surgedimensions and named, id for id, by that repo's
`LivingEnd/tools/art_contract.py`. 5,705,357 bytes. It adds:

- **Void Chamber vaults and trial spawners**: 14 item models (vault inactive, active, unlocking and
  ejecting; spawner inactive, active and ejecting; each plain and ominous) that the plugin draws
  over the real block. Vanilla's geometry with the inner walls pulled in to 0.25, so the plugin's
  slightly larger display stays in front of the real block's own inside. Obsidian-violet cage,
  purpur trim, a chorus-violet glow; ominous ones blacker, with end-portal teal and dragon's-breath
  pink eyes.
- **Keys and the Dragon Scale**: `void_key`, `ominous_void_key`, `dragon_scale`.
- **Mob skins** (equipment assets, humanoid and leggings layers): `hollowed`, `void_wraith`,
  `voidbound`; and `dragonwing`, the elytra as the Ender Dragon's wing.
- **The Skyray**: four bone models (`skyray_body`, `skyray_wing_left`, `skyray_wing_right`,
  `skyray_tail`) and their texture.
- **Animals**: the Lumen Cow, Duskhog, Starling, Voidhound (wild, tame, angry), Mire Frog and Hollow
  Cat textures.
- **Paintings**: `starfall`, `the_crown`, `lanternfruit`, `skyray`, `hush`.

It touches nothing outside `assets/livingend/`, so no vanilla texture changes for anyone. Every
model it adds uses textures under `textures/item/`, the only folder (with `textures/block/`) an
item model's atlas reaches.

## Updating a pack

Replace the zip, cut a new release, and update both the url and the sha1 in the server's
`config.yml`. The download url changes per release, so updating one without the other is the
usual way to break this.

## surgepack v19

Glyphs from the new `overlays:fx` font become fullscreen effects: bloom, vignette, crack and letterbox. The old `overlays:fullscreen_*` tint still works. `#FFD700` text gets a gold gradient.

This is a rebuild of v18 rather than an append, because two v18 files are replaced (the text shader pair). Every other entry is copied byte for byte.

## surgepack v22

The Season 2 opening's light, drawn by the shader in the world:
- **`overlays:world`**, a new font of six key glyphs (U+E820..E825). On a text display, our `rendertype_text` turns each one into a shape drawn in the world: a halo, a magic circle, a shockwave ring, a pillar of light, the supernova, or the seam. Every other glyph draws as before.
- **`rendertype_text_see_through`** (1_21_11 overlay): vanilla, plus the same world shapes for see-through displays (the supernova).
- **`rendertype_world_border`** (1_21_11 overlay): every world border is now drawn as aurora curtains over a hex lattice. It is violet when still, gold when growing, and rose when shrinking.
- **The opening's sky in steps**, built as v21 and never released on its own. It adds a made region after v20's sky window; v20's window is unchanged.

Rebuilt on v20: only the opening's staged files are rewritten, and the `rendertype_text` pair is replaced.
Served from: https://raw.githubusercontent.com/seeedey/surge-packs/c57ae9c7e9dd78d4446d6d863743b23a2120e3f4/surgepack.zip
